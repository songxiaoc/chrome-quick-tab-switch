# Quick Tab Switch

[English](README.md) | 中文

一个用于 Chrome 的轻量级标签页快速切换扩展。它会记录最近访问过的标签页，并通过快捷键在访问历史中后退或前进。

## 功能

- 使用快捷键快速切回上一个访问过的标签页。
- 支持在标签页访问历史中前进。
- 支持跨窗口切换，并自动聚焦目标窗口。
- 记录最近 20 个访问过的标签页。
- 使用 `chrome.storage.session` 保存会话状态，降低 Manifest V3 后台 service worker 休眠带来的影响。
- 当已经到达历史边界时，在页面顶部显示自动消失的文字提示，不弹窗、不打断操作。
- 浏览器启动恢复窗口时，会避免把启动过程中的自动激活事件误记录为用户切换历史。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt+Q` | 后退到上一个访问过的标签页 |
| `Alt+W` | 前进到更新访问过的标签页 |

如果快捷键和其他扩展或系统快捷键冲突，可以在 Chrome 的扩展快捷键设置页中修改：

```text
chrome://extensions/shortcuts
```

## 安装

1. 打开 Chrome 扩展管理页：

   ```text
   chrome://extensions
   ```

2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录：

   ```text
   chrome-quick-tab-switch
   ```

5. 加载完成后即可使用 `Alt+Q` 和 `Alt+W`。

修改 `manifest.json` 或 `background.js` 后，需要在 `chrome://extensions` 中重新加载扩展。

## 权限说明

扩展使用以下权限：

- `tabs`：读取和切换标签页。
- `storage`：保存当前会话中的标签访问历史。
- `scripting`：在达到历史边界时向当前页面注入短暂文字提示。
- `activeTab`：允许在用户触发快捷键后，对当前活动标签页执行提示注入。

扩展不会长期访问网页内容，也不会收集或上传任何数据。

## 注意事项

- `chrome://`、Chrome 网上应用店、部分扩展页面等受浏览器限制的页面不能注入提示文字；在这些页面达到历史边界时，扩展会静默跳过提示。
- 浏览器刚启动恢复上次会话时，扩展会在短暂恢复期内只记录当前页，避免尚未手动切换标签时就产生可后退历史。
- 标签页关闭后，对应记录会自动从历史中移除。
